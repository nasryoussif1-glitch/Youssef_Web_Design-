## 🌐 إعداد النطاق والاستضافة (Domain & Deployment: youssefwebdesign.com)

عند حجز نطاقك الرسمي `youssefwebdesign.com` من أي مزود (مثل Namecheap أو Cloudflare أو GoDaddy):

1. **الاستضافة السحابية (VPS أو Cloud Service):**
   - يمكنك رفع المشروع إلى خادم (Ubuntu VPS) أو منصات مثل **Railway / Render / DigitalOcean**.
   - ضبط متغيرات البيئة عبر ملف `.env` (مثل `PORT=5000` وبيانات الـ SMTP).
2. **سجلات الـ DNS (DNS Records):**
   - اضف سجل `A Record` يوجه `@` إلى عنوان IP الخادم الخاص بك.
   - اضف سجل `CNAME` يوجه `www` إلى `youssefwebdesign.com`.
3. **تفعيل شهادة الأمان HTTPS (SSL/TLS):**
   - باستخدام Let's Encrypt مجاناً عبر Certbot:
     ```bash
     sudo certbot --nginx -d youssefwebdesign.com -d www.youssefwebdesign.com
     ```
   - أو بتفعيل البروكسي المجاني عبر Cloudflare مع تفعيل وضع Full SSL.

## 🔒 الأمان والمصداقية (Security & Transparency)

- كلمات المرور مشفرة بخوارزمية `PBKDF2-HMAC-SHA256` مع 100,000 تكرار وSalt عشوائي لكل مستخدم.
- حماية الجلسات بواسطة رموز وصول مشفرة (Tokens) تُفحص في الخادم مع كل طلب.
- عزل ملفات الرفع في مجلد خاص وفحص امتداداتها لمنع أي ملفات تنفيذية خبيثة.
- حماية ضد هجمات مسارات الملفات (Directory Traversal Protection).
- وضوح تام في عرض النماذج كأفكار وبروتوتايب دون اختلاق عملاء أو تقييمات وهمية.
